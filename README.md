# 🚀 All-In-One Downloader — Tama-ID

**All-In-One Downloader** adalah halaman web downloader dengan tampilan modern dan responsif yang mendukung tujuh platform dalam satu tempat.

Dibuat oleh **Tama-ID**.

---

## ✨ Fitur Utama

- 📱 **TikTok** — Mengambil data dan pilihan link download video.
- 📸 **Instagram** — Mendukung pengambilan media foto dan video.
- 🎵 **Spotify** — Mengambil informasi lagu dan audio jika disediakan API.
- 🍎 **Apple Music** — Mengambil informasi lagu dan audio jika tersedia.
- ✂️ **CapCut** — Mengambil link video template jika tersedia.
- 📌 **Pinterest** — Mengambil gambar dari link Pinterest.
- 📁 **MediaFire** — Mengambil informasi dan link file.

## 🎨 Fitur Tambahan

- 🌙 Dark Mode dan Light Mode.
- 🔗 Auto Detect platform berdasarkan link.
- 📋 Tombol Paste untuk memasukkan link.
- ⚡ Tampilan modern dan responsif.
- 📥 Download menggunakan Blob.
- 🖼️ Preview media sebelum download.
- 💾 Pengaturan tema tersimpan di browser.
- 🛡️ Validasi URL dan nama file.

## 🚀 Cara Menggunakan

1. Buka halaman downloader.
2. Pilih platform atau tempel link secara langsung.
3. Sistem akan mendeteksi platform secara otomatis.
4. Tekan tombol **Download**.
5. Tunggu proses pengambilan data.
6. Pilih file yang ingin diunduh.

## ⚙️ API

Proyek ini menggunakan endpoint API eksternal dari:

`https://api.nexadev.my.id/`

Beberapa permintaan juga mencoba layanan proxy sebagai fallback apabila akses langsung mengalami kendala.

**Catatan:** Ketersediaan downloader bergantung pada API eksternal, struktur respons, CORS, dan kebijakan masing-masing platform. Tidak semua link atau jenis media dijamin berhasil diproses.
